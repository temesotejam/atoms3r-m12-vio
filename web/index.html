AtomS3R-M12 VIO

AtomS3R-M12 の Camera + BMI270 を使った軽量VIO試作です。

1. ファームウェアを書き込む

Chrome / Edge でAtomS3R-M12をUSB接続してから押してください。

初回書き込み時はデバイス内の既存プログラムが置き換わります。

2. シリアル確認

書き込み後、デバイスを再起動してから接続します。115200 baudです。

未接続

最初の確認

  1. 起動後約2秒は静止させます。
  2. [CAM] OK と [IMU] OK を確認します。
  3. POSE行のRoll/Pitch/Yawが回転に追従することを確認します。
  4. 模様のある壁や机を見ながら動かし、tracks が概ね10以上になるか確認します。
  5. 静止すると stationary=1 に戻ることを確認します。

v0.1の位置値はまだ完全なVisual Translation融合前で、短時間の慣性積分＋Visual stationary判定です。まずCamera/IMU/処理周期を実機で検証する段階です。
